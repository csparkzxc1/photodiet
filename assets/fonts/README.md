# Pretendard Fonts

Place the following font files in this directory before running the app:

- `Pretendard-Regular.otf`
- `Pretendard-Medium.otf`
- `Pretendard-SemiBold.otf`
- `Pretendard-Bold.otf`

Download from: https://github.com/orioncactus/pretendard/releases
